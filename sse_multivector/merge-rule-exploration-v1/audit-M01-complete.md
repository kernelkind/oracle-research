Its useful Christmas, photography and animal-flesh extensions remain real differences from M04. It also has weak small attachments and extremely broad upper unions. Missing some overlapping masks from an already discoverable note is not lost discovery; opposed positions and useful broad commonalities remain admissible.

Only this report was written. No code, inputs, generated hierarchy titles, memberships, display rules, models, tests, Cargo operations, commits or cards were changed by this inspection.

## Remaining uncertainty

There is no unread raw internal node under the declared direct-inspection/strict-reuse method. That does not mean all 915 nodes received equally long prose or every broad interpretation received equal scrutiny. Exact matches inherit the limitations of the original M04 audit. Semantic usefulness is a provisional analyst judgment, not a user approval or quantitative label.

Full original context helps distinguish mental fog, figurative fire, a chicken enclosure and a calendar proverb, but it does not put omitted words back into the frozen encoded masks. A weak association can reflect mask selection, vector geometry, the merge rule's accumulated choices, or more than one of these. Membership inspection alone does not prove which caused it. Neither depth, merge cost, subtree survival nor note count was treated as a semantic score.

The unresolved comparative work is an exhaustive search for **every meaningful alternate relation in every other run**, not missing raw-tree reading coverage here. Only the explicit relation checks cited above justify the strongest gain/loss statements.
