# M08: connecting parents

M08 retains useful beverage and food-preparation branches, but it does not establish a coherent complete top-level partition. Its smaller displayed tree is not a semantic verdict. Some weak pairs remain intact and simply acquire different parents.

## Inspection scope

The 87 disjoint reading boundaries contain all 916 canonical vectors, 945 original IDs and 2,490 mask fragments. All original masks, including different fragment arrays sharing an alias, were read again before this upper-tree assessment. The 64 new boundary subtrees are assigned to [audit A](audit-M08-complete-A.md) and [audit B](audit-M08-complete-B.md). The other 23 boundaries contain 43 canonical vectors and 20 inherited transitions with exact recursive matches to previously audited M04/M06/M07.

This report inspects their 86 connecting merges in ascending ID order. It does not flatten the actual hierarchy or declare those reading boundaries to be algorithm-selected segments. Complete originals were reopened for the ambiguous examples below; other frozen context has already been read in the preceding audits. No image, link target, generated title or new subject assignment enters these judgments.

## 1. Coffee and tea have an intelligible broader parent

Node 1131 joins coffee preparation 1038 with coffee drinking 1085. Its retained ancestors add coffee-shop music at 1353, caffeine at 1423 and dairy-in-coffee at 1534. Node 1723 then joins that 19-note branch with the three-note tea branch 1582.

Actual masks include:

- V294 · N038: ⟦Baby Got Back⟧ ⟦playing⟧ ⟦coffee shop⟧

- V334 · N042: ⟦I⟧ ⟦want⟧ ⟦hot tea⟧ ⟦too⟧

Preparation, consumption, venues and tea can broaden this branch without being the same activity. The N072 original uses tea as an analogy for soda-bread variation; that does not remove its explicit tea meaning.

Two qualifications remain. N034's full original mentions caffeine but never specifies coffee. V725 selects only a dog emoji, although its full N079 original is “Is there coffee for me? 🐶☕️” followed by an image URL. These have weaker self-contained mask evidence than the examples above. No missing beverage meaning is supplied by an unseen image.

## 2. Culinary branches remain meaningful despite varied recipes

Node 1652 joins onion-bearing food masks in 1506 with the vegetable/ingredient branch 1641. Node 1711 adds the risotto/shrimp and other dish branch 1688. The unchanged projection collapses 1711 because its parent 1763 has the same complete note set; it does not erase its memberships.

Node 1716 brings together the fruit/bread branch 1558 and the bread-preparation branch 1696. Bread types, ingredients and preparation are legitimate related variations. V756's cherry-fruit fragment broadens the fruit side; V893's spaghetti mixing/simmering fragment broadens the preparation side. Neither is evidence of a bread-only subject.

Other clear narrow descendants include brisket/smoker and crockpot material below 1705. Their wider parent 1747 also inherits the small tandoori-“fire”/hot-bread-pan group 1669. That possible heat connection does not establish identical cooking methods. This assessment keeps the distinction between useful descendants and less specific parents.

## 3. The daily-life branch has useful parts and ambiguous additions

Node 1562 joins sleep/time material in 1374 with morning/getting-started material in 1519. Node 1714 adds activity 1655; 1736 adds weather/morning observations 1328. These transitions have plausible broad relationships, but they do not certify every component's placement.

For example, V322/V323 select ⟦Fog is lifted⟧. N041's full original says:

> I think I got grasp on that fog/clarity meat eaters often mention.
> I fell asleep with the kids, very tired and kind of cold. Woke up at five and my brain was started.
> I don't feel I need a coffee to start living today. Fog is lifted and all.
> It might be just a good sleep, but I've had a very good sleep last days. Usually I'm up like three times, now I just sleep like a bear.
> #fasting #keto #carnivore

The phrase refers to mental clarity, not a weather report. Its placement within 1328 alongside frosty gardens and outdoor temperature is therefore not justified simply by reading “fog” literally. The available evidence does not isolate whether this comes from the short mask, its vector or the merge rule. Other N041 masks still provide sleep/caffeine access.

Changed earlier availability can still change which singleton pairs are eventually chosen; identical initial ordering does not imply identical complete histories.

## 5. Upper placement remains unresolved

The root 1830 has displayed children 1820 and 1829, containing 38 and 89 notes respectively; 27 notes occur in both. Such overlap is allowed: distinct vectors from one note can support different paths. Nor is the 89-note branch automatically incoherent because it is large in this food-focused sample.

The actual contents are mixed. Node 1820 combines coffee/tea, bread and taste material with wine/raw-milk and some confectionery masks. Node 1829 contains the broad food-preparation, ingredients, daily-routine, social advice, food-opinion, greeting, geographic and technical/tag branches. Useful local relationships coexist with inherited weak pairs and broad later joins. This is insufficient evidence for treating either root child as a polished, predictable navigation option.

The [relation comparison](audit-M08-relations.md) separately tests relevant note access through all previously admitted alternate masks. In particular, N064's photography-related masks enter a work branch, while N048/N080 art masks occur elsewhere. Counting those masks as present somewhere in the tree would not establish a focused photographic discovery path.
