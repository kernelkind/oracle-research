CREC-66 / CREC-62 GTE calibration runbook

Frozen contract

  calibration shard: 157
  token ceilings: 16,20,25,32,40,50,64,80,100,128,160,202,259,325,433,513
  total provider reservation: 25,000,000 micro-USD
  worker runtime allowance: 20,000,000 micro-USD
  setup, transfer, retrieval, and teardown reserve: 5,000,000 micro-USD
  minimum reserve left before worker start: 1,000,000 micro-USD
  GPU: one NVIDIA RTX PRO 6000 Blackwell Workstation Edition at 600 W
  host RAM: at least 128 GiB
  disk: 200 GB, at least 1 GB/s advertised bandwidth

No command in this file creates a second instance or retries calibrate-shards.
All directory copies use trailing slashes intentionally: Vast copies directory
contents with a trailing slash and nests the source directory without one.

Local layout

  <LOCAL_ROOT>/package       immutable package
  <LOCAL_ROOT>/preflight     free local exact-image preflight
  <LOCAL_ROOT>/launch        offer, instance, and provider records
  <LOCAL_ROOT>/work.partial  resumable retrieval; absent before retrieval
  <LOCAL_ROOT>/work          verified retrieved result; absent before retrieval

The exact IMAGE_REF and SOURCE_COMMIT come from the reviewed CREC-66 package.
IMAGE_REF is the docker.io/kernelkind/oracle-mvp@sha256:... value already stored
in package/run/calibration-config.json. DOCKER_PULL_PAT is a short-lived,
read-only Docker Hub token entered only for registry authentication.

2. Refresh and save one exact 200 GB offer

  mkdir "$LOCAL_ROOT/launch"
  date -u +%Y-%m-%dT%H:%M:%SZ > "$LOCAL_ROOT/launch/attempt.log"

  BASE_QUERY='gpu_name=RTX_PRO_6000_WS num_gpus=1 gpu_max_power=600 reliability>=0.995 cpu_arch=amd64 cpu_ram>=137.439 disk_space>=200 disk_bw>=1000 inet_down>=500 inet_down_cost<=0.02 inet_up>=100 inet_up_cost<=0.02 driver_version>=580.95.05 duration>=1 rentable=true verified=true'
  export OFFER_QUERY="$BASE_QUERY geolocation in [US]"

  vastai search offers \
    "$OFFER_QUERY" \
    --type on-demand \
    --storage 200 \
    --order dph_total \
    --limit 20 \
    --raw \
    2> /dev/null \
    > "$LOCAL_ROOT/launch/offers.json"

  Prefer a US offer. If offers.json is an empty JSON array, set
  `export OFFER_QUERY="$BASE_QUERY"` and repeat that exact command. Do not relax
  any other constraint. Record the exact query used:

  printf '%s\n' "$OFFER_QUERY" > "$LOCAL_ROOT/launch/offer-query.txt"

  Select one returned ID and set:

  export OFFER_ID=<OFFER_ID>

  select_offer() {
    python3 - "$1" "$OFFER_ID" "$2" <<'SELECT_OFFER'
import json
import sys
from pathlib import Path

source = Path(sys.argv[1])
offer_id = sys.argv[2]
destination = Path(sys.argv[3])
temporary = destination.with_name(f".{destination.name}.tmp")
destination.unlink(missing_ok=True)
temporary.unlink(missing_ok=True)

if not offer_id.isdecimal() or int(offer_id) <= 0:
    raise SystemExit("selected Vast offer ID must be a positive integer")

try:
    offers = json.loads(source.read_text(encoding="utf-8"))
except (OSError, json.JSONDecodeError) as error:
    raise SystemExit(f"could not read Vast offer list: {error}") from error
if not isinstance(offers, list):
    raise SystemExit("Vast offer search must return a JSON array")

matches = [
    offer
    for offer in offers
    if isinstance(offer, dict)
    and not isinstance(offer.get("id"), bool)
    and str(offer.get("id")) == offer_id
]
if len(matches) != 1:
    raise SystemExit(
        f"selected Vast offer {offer_id} must occur exactly once in the constrained list"
    )

temporary.write_text(
    json.dumps(matches, ensure_ascii=False, sort_keys=True, indent=2) + "\n",
    encoding="utf-8",
)
temporary.replace(destination)
SELECT_OFFER
  }

  select_offer "$LOCAL_ROOT/launch/offers.json" \
    "$LOCAL_ROOT/launch/offer.json"

  This local selection must produce a JSON array containing exactly the chosen
  row. The explicit `--storage 200` is mandatory because Vast otherwise prices
  only 5 GiB. The network-price ceilings prevent the package and image downloads
  from consuming the non-runtime reserve before the manual cost gate.

6. Manual provider-cost gate

  Read the provider's current total charge for this one instance, including
  setup, storage, and transfer. Start the worker only if that charge is at most
  4,000,000 micro-USD. This leaves at least 1,000,000 micro-USD for retrieval
  and teardown within the 5,000,000 micro-USD non-runtime reserve.

  If the charge is higher, do not run calibrate-shards. Seal, retrieve, destroy,
  and failed-settle the attempt. Before sealing, record the observed charge on
  the rented host so the refusal itself—not a successful preparation log—is the
  failure evidence:

  export SETUP_CHARGE_MICRO_USD=<OBSERVED_SETUP_CHARGE_MICRO_USD>
  test "$SETUP_CHARGE_MICRO_USD" -gt 4000000
  printf 'worker start refused: setup charge was %s micro-USD\n' \
    "$SETUP_CHARGE_MICRO_USD" \
    > /workspace/oracle-calibration/work/cost-gate-failure.log

  tail -f work/calibration.log

  calibrate-shards appends the one-time execution claim to
  work/budget-ledger.json before starting the model, then performs its own CUDA
  smoke encoding before shard 157. Never invoke it twice and never overwrite
  work/budget-ledger.json from the package after this point.

  The process is complete only when work/calibration.exit exists. On success it
  contains 0 and work/calibration-evidence.json exists. On failure, retrieve the
  claimed ledger and logs; do not retry.
